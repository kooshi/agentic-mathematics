name: ephodos-recognition
description: The deliberate procedure for finding the description under which an answer is forced, when none has come — in mathematics and in every field that argues from it, physics first. Invoke it the moment the Ephodos core's reflex (write the problem for a stranger in the field that owns it; ask the working argument which property it uses) has not fired: three attempts on one step have failed; the argument grows a clause per case; an answer found by computation or measurement resists derivation; a result is proved only for instances, or only for the case in which it was posed; a long calculation has produced a simple answer nobody can explain; a known theorem almost applies; a wall describes what a counterexample would have to carry; every step checks and the order looks arbitrary. Triggers on "why is this true," "is there a cleaner proof," "what is this really," "which theorem governs this," "this looks like …," "does this generalize," "can we avoid the case analysis," "the numbers say so but I can't prove it," "we keep adding cases," "is there a slicker way." Drives toward one terminal test: the description under which it is forced — the object stated by what determines the answer and by nothing that only accompanies it, named in the discipline where objects so stated already have a theory, that discipline's theorem carried across with each hypothesis discharged here and the one changed step named, and the statement placed at exactly the class its determiners define — or the honest exit: the object written for a stranger in its home field, that field's result read and shown silent, and the stall stated in its words for a fresh mind. The question stays fixed; when it must change, this is not the procedure, and when every home fails on a premise none of them earned, the description must be made rather than found (ephodos-invention). Assumes the Ephodos core is loaded; this is its companion, scoped to finding.

# Ephodos — The Recognition

The Ephodos core carries recognition as a reflex — write the problem for a stranger in the field that owns it; ask the working argument which property it uses — and dispatches here when no description forces the answer: three attempts on one step have failed, the argument has grown a clause per case, or an answer the computation found will not be derived. This skill is the ritual for that moment, and it is the finding half of the identity, the half of Archimedes' *Method* that found what "had to be demonstrated … afterwards." His own device was a recognition: he weighed the figure on a lever against figures whose centres of gravity were known, avoiding the integration that would naturally be used and making the solution depend, in Heath's words, "upon another integration the result of which is already known." The core states the move in a sentence because every turn cannot afford more; this skill spends the words, because recognition is where a model's prior is a resource without equal — it holds more columns of the dictionary than any person, the vocabulary of every field an object could be named in — and where the same prior does its quietest damage, returning the likeliest name for the words the problem arrived in, which is rarely the name under which it is a theorem.

The whole skill serves one terminal test: **the description under which it is forced.** Not a proof pushed harder in the vocabulary the problem came in, and not an analogy that feels right, but the object restated so exactly that a theory someone already built decides it — or says, with its hypotheses, exactly why it cannot. This standard has its lineage, beyond Aristotle's *that* and *why* that the core carries. Poincaré, of language well chosen: "all the proofs made for a certain object apply immediately to many new objects; there is nothing to change, not even the words," and "a well-chosen word usually suffices to do away with the exceptions." Hadamard, of arithmetic, "one of the most difficult, if not the most difficult branch of mathematics": essential gains on an arithmetical question are generally obtained "by reconducting it to higher algebra or to the infinitesimal calculus." And Kummer's theory, as Corry reads it, suffered from "the need to choose specific 'ideal numbers' in every particular case considered, thus obscuring the more general principles," where Dedekind's strength was "coming up with the correct settings where the problem should be analyzed." Recognition works inside a question already posed, its unknown, data, and condition fixed, and changes only the description of the object. It shares one move with whoever holds the frame — naming the discipline — and when the question itself must change, it hands the stalled form back to them. Drive toward the forced description deliberately; the procedure below is how.

<the_one_cut>
Every technique here serves a single discrimination: **what determines versus what accompanies.**

An object arrives dressed. It comes in the vocabulary of whoever posed it, at the instance where it was noticed, in the coordinates that were to hand, with the history of the attempts on it. Some of its features determine the answer: change one and the answer changes. The rest accompany it: change them and the answer stays. Descartes drew the line in his rules for the direction of the mind, with the riddle of Tantalus's vase: in Cousin's French, the figure of Tantalus on it "ne détermine nullement la question, mais seulement l'accompagne" — it does not determine the question at all; it only goes with it — and the rule he drew was to guard against supposing more than we have. Poincaré gave the reason the line runs where it does: mathematicians "n'étudient pas des objets, mais des relations entre les objets ; il leur est donc indifférent de remplacer ces objets par d'autres, pourvu que les relations ne changent pas." And van der Waerden stated Emmy Noether's maxim: relations between numbers, functions and operations "become perspicuous, capable of generalization, and truly fruitful, when they are detached from their particular objects and reduced to general conceptual connections."

Once the cut is made the description is nearly forced. Strip what accompanies and what remains is a short list of relations, and a short list of relations is the definition of a class: the nonzero residues modulo a prime, stripped of the prime, are a finite group; the pendulum's quarter period, stripped of the pendulum, is a complete elliptic integral, and named once more — its ratio to the small-swing period is the reciprocal of the arithmetic–geometric mean of 1 and cos(θ₀/2) — a quadrature becomes an iteration whose correct digits roughly double at each step: five steps give the period at θ₀ = 3 rad to sixteen digits. A class defined by a few relations that recur usually has an owner — some field has studied it — and the owner holds the theorem. Naming the home is then close to a lookup; the insight was the stripping. The same cut sets the statement's reach, which is the core's cut seen from the finding side: the answer holds wherever the determining relations hold, which is the class, and fails where one of them fails, which is the *not claimed* line.

Three mechanisms make the cut hard. The costume is the most visible part: the vocabulary an object arrives in was built to talk about its accompaniments — the setting, the instance, the coordinates, the method that found it — so the features easiest to name are the ones least likely to determine. Your retrieval is keyed by vocabulary: a theorem is filed under the words of the field that owns it, and an object in its costume's words retrieves arguments of the costume's kind, which is why fluent recall misses the theorem one field over. And your ranking is by likelihood: asked what an object is, you return the name these words most often carry, which is the costume's name again or its nearest neighbour — so the chooser the core asks for has to be supplied here as a procedure.

A feature is often consumed only through one of its consequences, and then it is not sorted whole: it splits. The consequence determines, the rest of the feature accompanies, and the split is the recognition's first step. Primality, in Fermat's theorem, is consumed only as "every nonzero residue is invertible"; sorted whole it determines — the argument uses it and n = 4 breaks the statement without it — and the statement stays at the primes. Split, the determiner is invertibility, and the class is every modulus. Ask of every feature the argument consumes which of its consequences the step actually uses, and sort that.

When you cannot say which side a feature is on, it is unsorted, and an unsorted feature is not treated as either. Vary it: compute the answer on the smallest cases with that feature changed and the rest held. If the answer moves, the feature is a candidate determiner; if it stays, a candidate accompaniment. Candidates both, because small cases agree by accident, and the argument settles it: a feature determines when the argument consumes it and a counterexample exists without it; it accompanies when an argument runs without it.
</the_one_cut>

<read_the_stall>
Before recognizing anything, read the stall, because its shape says which features are misplaced. Each dispatch condition is the wrong description reporting where it is wrong.
- **A clause per case.** The cases share a determiner the description does not name, and the description is splitting one class along an accompaniment. Line the cases up, strike what varies, and what remains is the relation the argument should run through. Poincaré's warning that exceptions "hide the laws" is the diagnosis, and Weil's letter shows the cure: the proofs he set aside gave "a special role, in the proofs, to the point at infinity, sweeping the problem into a corner," and his own was "birationally invariant (that is to say, not attributing a special role to any point)."
- **An answer found and not derived.** A number that a computation or a measurement produced, and that a derivation in the problem's own words cannot reach, is the *that* without the *why*. Ask in which field this number is a theorem.
- **A long calculation with a simple result.** The simplicity is a relation the calculation walked through without naming. The result is not finished until you could have foreseen it; the core's look-back says why.
- **A result proved only at instances.** Either the argument uses a property the whole class has, or the instance has a property the class lacks; the core's *uses only* says which. Hadamard's history of the calculus is this stall at historical scale: Torricelli and Fermat "treated special cases whose properties concealed the general principle."
- **A known theorem that almost applies.** One hypothesis fails as the object is described. Either the object satisfies it under another description, or one step of the theorem's proof must change, or the failing hypothesis is the finding.
- **Two descriptions that both apply, and disagree.** Not an absence but a collision: each description has a home and a theorem, and the theorems contradict each other on this object. Recognition's work is to state both, in their homes' words, and to find the premise they share. If that premise is earned, one description has misapplied its theorem, and the transfer's hypothesis lines will show where. If it is not earned, no home that shares it will clear the collision: search once for a field that has already revised it, and if none is found, the description has to be made.
- **A wall that describes a counterexample.** A no-go says what a counterexample would have to carry, and describes a class that may be empty. The description that moves such a question is the one that asks what every actual solution carries.
- **Three attempts on one step.** The premises you hold make that step long. It is short from some other set of premises, and the question is whose.
- **Every step checks and the order looks arbitrary.** The argument is valid and not understood; Poincaré's exacting reader wants to know "why they link together in this order rather than another." What is missing is the description under which the order is forced.

Poincaré's siege is the model for reading a stall: "all my efforts only served at first the better to show me the difficulty, which indeed was something." A stall located exactly is half a recognition, because the exact place where a description fails is where the determiner it lacks would act.
</read_the_stall>

<the_stranger>
The first instrument for the cut, the cheapest, and in the record this identity was distilled from the one that paid most: write the problem for a stranger — a working researcher in the field that owns the object, who has never seen the work — in that field's vocabulary, and name the field. Do it on the page, in this order.
1. **Name the reader.** "A number theorist," "a probabilist," "someone who works on elliptic integrals," "a fluid dynamicist." If no field comes, write three short versions for three fields. Grothendieck: "Every viewpoint leads to the development of a language which is best suited to expressing it," and having several viewpoints "also means (at least in mathematics) having several different languages to tackle the situation." The field that comes first is usually the costume's; the one that does not come until asked is often the owner.
2. **Write it standalone.** The unknown, the data, and the condition; every term defined from the reader's primitives; nothing from the work's own vocabulary; no history of attempts, no names the work coined, nothing the reader would have to ask about. The test is that the reader could start work cold. Hilbert quoted "an old French mathematician" on the standard: a theory is not complete "until you have made it so clear that you can explain it to the first man whom you meet on the street." Your stranger is a colleague one field over rather than a passer-by, and the standard is the same: nothing presupposed that the reader does not hold.
3. **Mark every word the reader would stop at** — every word their field does not use as you used it. Each is one of two things. An accompaniment — a coordinate system, a coined name, a piece of the history — that translating showed was never needed: strike it. Or a determiner the reader's field has no word for: that relation is the new part of the problem, the thing to derive, and everything else has a home.
4. **Write the sentence "This is a …"** — the object named in the reader's own word. Pólya wrote to Hadamard that "the decisive idea which brings the solution of a problem is rather often connected with a well-turned word or sentence. The word or the sentence enlightens the situation, gives things, as you say, a physiognomy." Poincaré's two illuminations had this grammar exactly, one object "identical with" another field's. Then write what the field holds about objects of that name — its standard theorems, each with its hypotheses — before any argument of your own.
5. **Search in those words, and read what comes back.** The write-up is the query. The vocabulary that finds the theorem deciding the question also finds the paper that already decided it, so the home theorem and the novelty search arrive in one act, with the queries and hits recorded as the core's prior-art field asks.
6. **Give it to a fresh reader, and ask for the theorem that governs it.** The write-up is the unit a mind without your context can work on, and a fresh reader has no groove and a different prior. Ask what governs the object, not whether your approach works; the first question invites the recognition, the second invites a verdict on your costume.

Why it works, so that it can be done on purpose: the home field's words retrieve the home field's theorems, as the cut's second mechanism says. Translation performs the cut, because defining a term from another field's primitives forces you to say what the term is, and what it is turns out to be a relation or nothing. The explainer's attention is not narrowly directed: Helmholtz saw the ophthalmoscope "while preparing a lecture on that result of Brücke," a consequence the discoverer had not drawn. And the write-up is a derivation attempt in disguise: once the object is named, the home's theorem decides the question or says why it cannot, and either is cheaper than a fourth attempt or another day of computation. Write it before the fourth attempt, and before any large computation is launched, not after.

Two failures ride with it. The translation can be a change of costume and nothing more — the same argument in new words — and the tell is that nothing in the reader's field applies that did not apply before; the renaming has been done and the naming has not. And a write-up that the stranger could not start from cold has kept a word of the work's vocabulary, which is where the determiner is usually hiding.
</the_stranger>

<the_features>
Now list the object's features on the page, one line each: the feature; *determines*, *accompanies*, or *unsorted*; and the receipt. A list held in the head keeps the features already noticed and drops the one doing the work.

Draw the features from everywhere the costume hides them: every hypothesis of the statement; every object the problem names and every property it states or implies of each; the instance at which it was posed; the coordinates, units, and representation; the method by which the answer was first found; and every step of the best failed argument, since each step consumes a property.

Sort them with the canon's instruments, cheapest first.
- **What the working argument consumes.** For each step of the best argument so far, name the property it uses. A property used is a candidate determiner; a hypothesis never used is a candidate accompaniment — Pólya's "did you use the whole hypothesis?", read backward.
- **Pappus's analysis.** Assume the answer found and ask what it must carry; each consequence is a necessary condition only, and each is a determiner of the answer's shape. Poincaré built his thetafuchsian series this way: "I asked myself what properties these series must have if they existed."
- **Proclus's absence test.** For each candidate: would the conclusion still hold with it absent? Then it is a sign, not the cause.
- **Variation on small cases.** Change one feature, hold the rest, compute. Write each result as a control. A determiner's receipt is a control whose planted fault removes it, and which fires. An accompaniment's receipt is an invariance: put the varied cases into the run itself and print one answer across all of them — or the number of distinct answers — with a fault that removes a determiner instead. A fault that removes an accompaniment changes nothing, cannot fire, and fails the gate, as it should: an unchanging output is not a check.
- **Every solution.** Ask not whether one solution exists but what every solution carries. A relation every solution carries determines the solution set, and a wall that describes what a counterexample would carry is the cue to ask it.
- **The symmetry of the set-up.** Where the answer has a symmetry, find the symmetry of the problem it comes from. Lange's example is d'Alembert's theorem: the nonreal roots of a real polynomial come in conjugate pairs because the axioms of complex arithmetic are "invariant under substitution of i for -i."

A feature is sorted when it has its receipt. *Determines*: the argument consumes it — or consumes a consequence of it, and then the consequence is what is sorted — and a counterexample exists without it. *Accompanies*: an argument runs without it, or the variation left the answer fixed and an argument confirms it. The unsorted lines are the work that remains. When every line is sorted and the determiners are few, the next section is close to a lookup.
</the_features>

<the_homes>
The determiners, written plainly, are a short list of relations, and the question now is who has studied objects with exactly those relations. Ask it as a step, on the page, because recognition waits to be asked: Gick and Holyoak's subjects, who had just read a story with the answer's exact shape, produced its solution three times in fifteen without a hint — and two of those three said they had not thought of the story — and eleven times in twelve with one.

The first home is your own: the results this work has already derived and the sources it already holds, read by their bodies and not their titles, because the bearing of a held result sits in a subordinate clause, an inequality, or a quantifier far more often than in its headline. Two held results never set side by side are a theorem not yet found. Then the literature of the poser, whose own works are the nearest home outside the work. Then the fields.

Write several candidate homes, never one. Weil described his work as "deciphering a trilingual text" of whose three columns he held "only disparate fragments"; the columns are the candidate homes, and the fragments are what each already holds. For each candidate write three things: the name the object has there; the theorem that field holds about objects of that name, with its hypotheses; and the dictionary — each term of the problem beside its term in the home, one line each. Pólya's rule is that analogous objects "agree in certain relations of their respective parts," and stating such an analogy for rectangle and box took a common word, "bounding element": a dictionary with a blank line has not found its word. Aim, then scatter. Hadamard's hunting cartridge needs "a proper scattering. If this scattering is too wide, it is useless to aim; but if it is too narrow, you have too many chances to miss your game by a line"; and Souriau's rule, as Hadamard gives it, is that "in order to invent, one must think aside." Poincaré: the most fruitful combinations will often be those "formées d'éléments empruntés à des domaines très éloignés." The home nearest the costume comes to mind first and is least often the one. Your breadth is the resource here and your ranking by likelihood is the trap, so spend the breadth on purpose: for each candidate the question is not whether it is plausible but whether its theorem applies.

Test each home before adopting it, and write the result down.
- **The old proofs apply at once.** The home's proofs, run on this object, need nothing changed — or exactly one step, which the transfer names.
- **The exceptions vanish.** A clause per case in the old description becomes one statement in the new, and no point keeps a special role. If the cases survive the translation, the home has the costume's shape and not the object's.
- **It predicts a neighbour.** The home's theorems say something about this object that the old description could not have said, checkable on a case. A home that only explains is a restatement.
- **The dictionary holds both ways.** Every relation the home's argument uses holds on the problem's side, term by term. The dictionary is a claim, and one false line of it is the whole failure.

A home can deceive, and the canon says how. Weil: the analogies offer "material enough for many seductive mind-games, some of which are likely to be deceptive." Plato's Socrates, of discovery through names: whoever begins in error "may have forced the remainder into agreement with the original error," like "geometrical diagrams, which have often a slight and invisible flaw in the first part of the process, and are consistently mistaken in the long deductions which follow" — so consistency inside the new description is no evidence it began right. And a home that has served well can mislead: on the Dirichlet problem Hadamard reached for a single-layer potential where a double layer was needed, and found that "physical interpretation, which is in general a very sure guide and had been most often such for me, misled me in that case." A recognition is a conjecture until its transfer is written.
</the_homes>

<the_transfer>
A home's theorem crosses as a derivation, never as an allusion. Write three lines.
- **The theorem, read.** Its statement from the source, not from memory; everything built on a recalled theorem is held until it is read — or proved in the form you need, which for a textbook theorem is often shorter than the search. A recognition that arrives fluently is often the memory of a paper in which someone already named this object, which is why the reading is also the novelty search; one study of a frontier model's work on open problems warned of "subconscious plagiarism," "whereby AI reproduces knowledge of the literature acquired during training, without proper acknowledgment" `[t½:~12mo]`.
- **Each hypothesis, discharged here.** One line per hypothesis, with where it holds for this object: a step of the argument, a computation, a definition. A hypothesis checked against the memory of the object is not checked.
- **The one step that must change, named.** A theorem carried to a new object usually carries whole except for one step that used a property the home's objects have and this object lacks. Name that step and prove its replacement. The failure is the proof carried past its scope without it, and it has measured faces: a frontier model claimed a step "can be proved using the Lovász extension," which serves "only for submodular functions, and fails for weakly submodular ones"; another expanded a series about a point where its radius of convergence is zero; and in one physics benchmark, whose commonest failure was the wrong choice of model or formula, models in condensed matter "often rely on partially matching but ultimately inappropriate theoretical templates" `[t½:~12mo]`. Each is a transfer whose changed step went unnamed.

A theorem of physics carries a hypothesis mathematics does not: the regime. A home result about an idealization transfers only where the idealization holds, so the regime number is computed for this object before the result is used. The commonest slogan in the field is a transfer with a hypothesis dropped: Noether's theorem gives a conserved quantity for every continuous symmetry of an action, and carried to a damped oscillator it fails at the hypothesis, not the symmetry — the dynamics are unchanged by a shift in time, come from no action invariant under that shift, and lose energy.

Two checks close the transfer. **The remaining step is not the problem renamed.** A transfer can carry the whole difficulty into one remaining step that is the original problem in the home's words, and read as progress; in one formal proof-search study the agent often left a single unproved helper lemma that "reiterated the target statement in a slightly different form," and "explicitly prompting against this behavior failed to prevent it" `[t½:~12mo]`. Before believing a recognition, ask whether the remaining step is the original problem renamed; if it is, the home was a mirror. **The dictionary, reversed.** The result, carried back through the dictionary, is a statement about the original object in the original words, and it gets the core's entry: *uses only* read off the transferred argument, *not claimed*, a converse if it is two-way, and a model.
</the_transfer>

<the_class>
The determiners define a class, and the statement belongs there, no wider and no narrower. Specialize the cases to find the property; state the result where the property holds. Pólya's octahedron is the whole move: asked to bisect it by a plane through a given line, one invents the problem for any solid with a centre of symmetry, and "the main achievement in solving the special problem was to invent the general problem," because inventing it "disentangled that property of the octahedron which is essential for the problem at hand." The inventor's paradox says to try it first, and the cut says why: the general problem, freed of its accompaniments, has fewer things in it to be wrong about. Pólya's ships run the other way: "Rest is a special case of motion. And motion is relative" — a special case solved, then lifted to the general one by an invariance.

The limit comes from the same cut. A statement wider than its determiners reach has dropped one, which is the core's over-claim; and a statement so general that it says nothing is Hardy's "insipidity" — "a property common to too many objects can hardly be very exciting" — and Whitehead, whom Hardy quotes on his side: "it is the large generalization, limited by a happy particularity, which is the fruitful conception." The happy particularity is the determiner. The instance the problem arrived at then becomes a corollary, and its entry says so: derived from the class statement, its own statement quoted verbatim wherever it was first entered.
</the_class>

<when_it_will_not_come>
When every feature is sorted, every candidate home tested, and still no description forces the answer, four honest moves remain. The stall is stated in the home field's words first, always; then one of the other three, as the stall points: to whoever holds the frame when the question must change, to invention when the killed homes share a premise none of them earned, and to a fresh mind otherwise.
- **State the stall in the home field's words.** The smallest open form of the question, written for the stranger, is a result — the one relation that no home holds — and it is the next mind's starting point. Its entry's verdict is *stalls at*, with that relation named.
- **Propose a change of the question's sense, and hand it back.** Hilbert: a problem that resists is often sought "under insufficient hypotheses or in an incorrect sense," and its settlement may be a proof that it cannot be solved as posed. Weil, reporting Poincaré, describes the same turn: after searching "for a long time and in vain to solve this problem by a foreordained procedure, mathematicians inverted the question." But the question belongs to whoever posed it. Propose the change with its reason, and do not take it.
- **Remake the premise every home shares.** When the killed homes all failed on the same line of their dictionaries, and that line is a premise none of them earned — held only because every description held it — no home that shares it will find the description. Search once more, in the words its revision would carry — its negation, the object it would admit — for a field that has already revised it; found, it is a home, and the transfer carries it across. If none is found, the description has to be made, and the killed homes, each with the line that killed it, are the licence to make it: `ephodos-invention`.
- **The provisional drop, to a fresh mind.** Hadamard's rule: "to drop it and try something else, but to do so provisionally, intending to resume it." The forgetting hypothesis he reports from Woodworth gives the reason — the thinker "slides insensibly into a groove and may not be able to escape," and incubation "would consist in getting rid of false leads and hampering assumptions." For you the groove is literal: a context that has pushed three times holds the three attempts. Give a fresh mind the stranger's write-up and the sorted features, which are what the failed attempt chose, and nothing of how it failed. Never a fourth push in the same context.
</when_it_will_not_come>

<the_look_back>
A recognition that has landed is not finished until it has paid what it owes.
- **Could it have been foreseen?** Leibniz's mark of perfect knowledge is that nothing about the thing lacks its reason, "et qu'il n'y a point de rencontre dont on ne puisse prédire l'événement par avance." Once named, the result should look like the first thing the home's practitioners would say.
- **Does it deform into its neighbours?** Vary a determiner and watch the argument deform into the neighbouring theorems — Steiner's test that a proof explains, by "an array of 'deformations' of the original proof." Each neighbour the home predicts is a fresh chance for the recognition to be refuted.
- **What else does the home say?** The name brought a theory; read what else it holds about this object, and draw the consequences.
- **Is it new, in the new words?** Search again in the home's vocabulary. Weil's warning about a school that, unable to read another's language, "rediscovered sometimes with a great deal of effort, in their dialect, important results that were already known" is the price of skipping it.
- **Is the analogy spent?** Weil: "Once it is possible to translate any particular proof from one theory to another, then the analogy has ceased to be productive for this purpose," and it ends altogether with "a meaningful and natural way of deriving both theories from a single one." A dictionary that translates every proof is a theorem waiting to be stated.
- **Write down how it was found.** Keep the stranger's write-up, the sorted features, the killed homes, and the dictionary beside the entry. The next stall will stand on a feature already sorted, and the texts you learned from erased exactly this part.
</the_look_back>

<read_the_ugliness>
Each of these is the recognition reporting that it is being faked, and each names where to go back to.
- **"This is just like X," with no dictionary.** An analogy felt and not stated. Write the columns, term by term.
- **The first home that came to mind, adopted.** The costume's neighbour. Back to `<the_homes>`; write two more.
- **A write-up with a word the reader would stop at.** The determiner is hiding in it. Back to `<the_stranger>`, step 3.
- **A new name that predicts nothing.** A change of costume. Back to the tests.
- **The remaining step is the problem renamed.** A mirror, not a home. Derive the equivalence, and kill the home.
- **A home theorem with its hypotheses unlisted, or discharged from memory.** A proof carried past its scope. Back to `<the_transfer>`.
- **A home theorem recalled and not read.** Held until read — and read it, because the paper that has the theorem may have the result.
- **Cases that survived the translation.** The home has the costume's shape. Another home, or another sort.
- **A feature sorted by feeling.** No receipt, no sort. Vary it, or find the step that consumes it.
- **The class wider than its determiners reach, or the instance filed after the class was found.** The core's cut failing, in either direction, at the last step. Back to `<the_class>`.
- **A fourth attempt in the same context.** The groove. Write for the stranger, and give it to a fresh mind.

Push harder on none of these. Return to the features list with the smell as the sharper instruction.
</read_the_ugliness>

<the_loop>
Recognition is a loop over the features list: read the stall → write for the stranger → sort the features, with receipts → propose several homes, each with its dictionary → test each → carry one across, hypotheses discharged and the changed step named → place the statement at its class → look back. Each pass sorts an unsorted feature or kills a candidate home. Homes are unbounded and every new argument adds features, so the loop does not end by construction; it ends at a **state** — the forced description written as a derivation entry with its controls, or the stall stated in the home field's words and handed on — or at the economic stop, or at the provisional drop. It never ends at the first home that explains.

Three stops bracket it. The economic stop: when the cheapest untested home costs more to test than the result is worth, say so with the arithmetic; the call is the principal's.
