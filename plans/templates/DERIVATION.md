# M-nn — ‹name›: the derivation file

*The milestone's theorem record, written by its record job: every theorem the milestone proved, as an entry in the `ephodos` identity's
grammar (`derivation:` blocks with `statement:`, `uses only:`, `not claimed:`, `argument:`, `verdict:`, `grade:`, `minds:`, `prior art:`
and `handoff:` fields — `.claude/skills/ephodos/scripts/example-clean.md` is a passing example), its argument an address in the job
records, and under each entry, in prose, what rests on it. Copy to `plans/Mnn-derivation.md`. It must pass
`python3 .claude/skills/ephodos/scripts/derive_gate.py all <this file>`, because the gate resolves every address and runs every
control, so an entry whose argument has moved or whose control no longer passes is caught before anyone builds on it.*
