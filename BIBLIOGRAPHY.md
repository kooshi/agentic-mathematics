# Bibliography

*Every external work this project cites, reproduces, depends on, or corrects has an entry here, added the day it is first used.
Each entry records **(i)** what of ours rests on it, **(ii)** where our copy is, and **(iii)** how much of it has actually been
read — by section wherever the read was partial. *Why:* prose is not an index — a work named only in a plan is never found again —
and an abstract read is easily remembered as a paper read, then cited for what it does not say. A theorem in `CLAUDE.md` § Frontier,
or a grokking, that rests on prior art names its entry by the key in column one of § A. `tools/bib_audit.py` fails on any cited key
or arXiv id that resolves to no row. Current state only; Keryx is this file's writer, filing rows the lanes propose.*

*The paper library: ‹PRINCIPAL: where held copies live, relative to the repository or as a name, never a personal path›. Never
commit a paper's PDF; its licence is rarely ours.*

## D. Standing rules for this file

- A row is added the day the work is first used, not at the close.
- Reading status is per section; "recalled, not read" is said where it is true.
- Before calling a paper unheld, grep this file by arXiv id and Zbl number, and look in the library.
